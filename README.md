# My .vimrc

My .vimrc configuration and vim color schemes.

Most of the stuff taken from [here](https://amix.dk/vim/vimrc.html)
## Windows
- vimrc file
```
cp .\_vimrc ~\
```
- colors
```
cp ./solarized.vim 'C:\Program Files\Vim\vim91\colors\'
```
alternatively you can open folders and copy it from GUI
```
start .
start 'C:\Program Files\Vim\vim91\colors\'
```
## Linux
- vimrc file
```
cp .\.vimrc ~\
```
- colors
```
whereis vim
# copy accordingly, E.g
cp *.vim /usr/shared/vim/vim91/colors
```
